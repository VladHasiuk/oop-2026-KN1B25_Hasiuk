# Лабораторна робота №01

**Тема:** Створення та організація проєкту на C#/.NET у середовищі Visual Studio  
**Варіант:** 8 — Служба доставки  
**Проєкт:** DeliveryApp

## Мета

Ознайомитися з організацією програмного проєкту на платформі .NET, створити
консольний проєкт мовою C#, організувати простір імен та початкові класи
предметної області.

## Хід роботи

### Завдання 1. Створення проєкту

Створено консольний проєкт `DeliveryApp` (шаблон Console App, C#).

### Завдання 2. Класи предметної області

Створено каталог `Models` та простір імен `DeliveryApp.Models`, у якому
оголошено два класи:

- `Parcel` — властивості `Number`, `Weight`, `Recipient`;
- `Courier` — властивість `Name`.

### Завдання 3. Створення та використання об'єктів

У файлі `Program.cs` підключено простір імен `DeliveryApp.Models`, створено по
два об'єкти кожного класу та виведено інформацію про них у консоль.

## Структура проєкту

```
DeliveryApp
│
├── Models
│   ├── Parcel.cs
│   └── Courier.cs
│
├── Program.cs
└── DeliveryApp.csproj
```

Створено працездатний консольний .NET-проєкт з організованим простором імен та
